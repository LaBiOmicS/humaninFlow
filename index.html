Scientific Rationale

Engineered for Homology-First Mitochondrial Peptide Discovery

Humanin and the Small Humanin-Like Peptides (SHLP1–6) are encoded by short open reading frames within the 16S rRNA gene (MT-RNR2). Traditional gene predictors consistently miss them because they reside within a structural non-coding RNA. humaninFlow standardizes their systematic discovery across thousands of mitogenomes with mathematical rigor.

100% Data-Agnostic

Accepts single FASTA files, directory globs, or massive multi-FASTA assemblies without hardcoded species assumptions. Handles both circular mitogenomes and linear contigs.

Dual-Engine Architecture

Identical scientific results whether executed through Nextflow DSL2 (with native Cloud/Slurm executors) or Snakemake (with declarative rule DAGs).

Cryptographic Provenance

Every prediction is stamped with input SHA-256 digests, parameter fingerprints, software versioning, and calibrated bitscores, ensuring full auditability and reproducibility.

Run humaninFlow Anywhere

Choose your preferred workflow engine below. Both implementations share identical command semantics, container bindings, and output formats.

Nextflow DSL2 Execution

Designed for cloud scale, AWS Batch, Slurm clusters, or local workstation dispatch. 

# Run on local cohort using Conda/Mamba
nextflow run workflow/nextflow/main.nf \
  --input "cohort/*.fasta" \
  --outdir results/ \
  -profile conda

# Run using Apptainer (Singularity) on HPC Slurm Cluster
nextflow run workflow/nextflow/main.nf \
  --input "cohort/*.fasta" \
  --genetic_code 2 \
  --circular \
  --outdir results/ \
  -profile apptainer,slurm

Key Nextflow Parameters

  • --input <glob>: Path to mitogenome FASTA files
  • --genetic_code <id>: NCBI code (default: auto, or 2,5,9)
  • --circular: Circular topology for origin spanning
  • --outdir <path>: Output destination directory

Container Profiles

Switch profiles on the fly with -profile conda, -profile docker, or -profile apptainer. No local software installation needed beyond the container engine.

Snakemake Execution

Ideal for declarative DAG management, strict file-target tracking, and reproducible academic pipelines. 

# Execute using isolated Conda environments across all CPU cores
snakemake --snakefile workflow/snakemake/Snakefile \
  --config input_dir=data outdir=results \
  --use-conda \
  --cores all

# Execute using Apptainer containers
snakemake --snakefile workflow/snakemake/Snakefile \
  --use-apptainer \
  --cores 8

Snakemake Configuration

Configure runtime settings directly via workflow/snakemake/config/config.yaml or pass overrides via --config param=val.

Reproducible Environments

Uses strictly locked Conda recipes in workflow/snakemake/envs/humaninfinder.yaml for zero dependency drift.

Output Specifications

Standardized Deliverables

Every pipeline run generates clean, publication-ready outputs designed for seamless integration into downstream statistics, docking, or phylogenetics.

Master Matrix

results/summary/cohort_humanin_summary.tsv

Combined tabular matrix featuring every sample, peptide coordinates, strand, frame integrity (Complete / Incomplete / Interrupted), bitscores, and full translated amino acid sequences.

Multi-FASTA

results/summary/cohort_peptides.fasta

Publication-ready FASTA containing translated mature sequences for Humanin and SHLP1–6 across all cohort members.

Per-Sample Tracks

results/raw_predictions/<sample>_results.gff3 & .bed

Genomic annotation tracks compatible with IGV, JBrowse2, and UCSC Genome Browser, accurately representing origin wraps.

Audit Log

results/raw_predictions/<sample>_run.json

Full cryptographic provenance log containing input FASTA SHA-256 digest, exact parameters, PyHMMER version, and execution timestamps.
