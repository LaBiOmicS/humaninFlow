Scalable discovery of Humanin and mitochondrial micropeptides.

humaninFlow is a data-agnostic, publication-grade workflow framework designed to systematically locate, validate and annotate Humanin and SHLP1–6 across circular mitogenomes, population cohorts, and whole nuclear genome assemblies.

Pipeline Architecture

Decoupled stages ensuring data integrity, parallel discovery, and automatic metadata integration.

Stage 1

Pre-flight Linting

Validates FASTA syntax, ambiguous IUPAC codes, empty lines and duplicate record headers using humanin-finder lint.

Stage 2

Syntenic HMM Search

Aligns vertebrate profile HMMs to pinpoint the exact homologous MT-RNR2 locus window before frame translation.

Stage 3

In Silico Translation

Translates the species' native reading frame under specified genetic codes (Table 2/1/5), checking PF15040 domain gathering thresholds.

Stage 4

Cohort Synthesis

Joins prediction matrices with sample covariates, extracts unique non-redundant peptide alleles, and renders Markdown reports.

Dual Orchestrators

Deploy using Nextflow DSL2 for high-throughput cloud execution (AWS Batch, Google Cloud, SLURM) or Snakemake for local workstation and Conda environments.

Nested sORF Resolution

Standard gene finders fail inside ribosomal RNA. humaninFlow maps the locus synteny first, bypassing the non-coding structural annotation barrier.

Metadata Integration

Directly joins predictions with epidemiological, clinical and experimental covariates (e.g., Tumor vs Control, host breeds, geography, clades).

Quick Start

Choose your workflow manager and execute the pipeline in seconds.

Nextflow Execution 
# 1. Clone the repository
$ git clone https://github.com/LaBiOmicS/humaninFlow.git
$ cd humaninFlow

# 2. Run with Nextflow on any FASTA dataset
$ nextflow run workflow/nextflow/main.nf \
    --input examples/test_mitogenomes.fasta \
    --metadata examples/test_metadata.csv \
    --outdir results/nextflow \
    --table 2 \
    --circular
Snakemake Execution 
# 1. Clone the repository
$ git clone https://github.com/LaBiOmicS/humaninFlow.git
$ cd humaninFlow

# 2. Run with Snakemake
$ snakemake \
    --snakefile workflow/snakemake/Snakefile \
    --config input_fasta=../../examples/test_mitogenomes.fasta \
             metadata=../../examples/test_metadata.csv \
             outdir=../../results/snakemake \
    --cores 4
Containerized Profiles 
# Run Nextflow with official container images (zero local dependencies)
$ nextflow run workflow/nextflow/main.nf -profile docker --input data.fasta
$ nextflow run workflow/nextflow/main.nf -profile apptainer --input data.fasta

Execution Recipes

Data-agnostic execution patterns tailored for standard genomic tasks.

1. Vertebrate Population Cohorts

Complete circular mitogenomes evaluated under the vertebrate mitochondrial code (NCBI Table 2):

nextflow run workflow/nextflow/main.nf \
  --input mitogenomes.fasta \
  --metadata cohort_metadata.csv \
  --table 2 --circular

2. Nuclear Genome (NUMT) Search

Scan draft contigs or chromosomes for nuclear mitochondrial insertions under the standard code (Table 1):

nextflow run workflow/nextflow/main.nf \
  --input nuclear_wgs.fasta.gz \
  --command scan --table 1 --circular false

3. Invertebrates & Non-Vertebrates

Execute with alternative clade codes, e.g. Table 5 for insects or Table 9 for echinoderms:

nextflow run workflow/nextflow/main.nf \
  --input drosophila_mt.fasta \
  --table 5 --circular

4. Institutional HPC Cluster (SLURM)

Dispatch batch jobs to institutional compute clusters using Apptainer/Singularity containers:

nextflow run workflow/nextflow/main.nf \
  -profile apptainer \
  --input massive_cohort.fasta \
  -process.executor slurm -process.queue batch

Outputs & Data Dictionary

Standardized, auditable deliverables structured for immediate statistical and structural modeling.

Deliverable Type Biological & Technical Description
<prefix>_results.csv CSV Tabular discovery ledger: sample ID, peptide name (Humanin, SHLP1–6), frame status (Complete, Interrupted, Incomplete), coordinates, synteny bitscore, HMM bitscore.
<prefix>_results.fasta FASTA Translated amino acid sequences with detailed header annotations (coordinates, status, evidence tier).
<prefix>_results.gff3 GFF3 Standard 1-based genomic feature track for genome browsers (IGV, JBrowse).
<prefix>_results.bed BED 0-based half-open coordinates with circular wrap blocks split properly.
cohort_humanin_summary.csv CSV/TSV Integrated master ledger merging locus predictions with user-supplied covariates (tumor/control, breed, country).
cohort_unique_peptides.fasta FASTA Non-redundant unique peptide variants found across the cohort, ranked by observed frequency.
COHORT_ANALYSIS_REPORT.md Markdown Executive report summarizing discovery rates, completeness percentages, and variant distribution.

Scope & Evidence Tiers

Clear epistemic boundaries for in silico homology predictions.

✔ What humaninFlow tells you

  • Where the homologous position of each peptide lies in MT-RNR2.
  • Whether the species' native reading frame is complete, incomplete, or interrupted.
  • Whether the locus follows the vertebrate pattern and reaches the PF15040 gathering threshold.
  • How peptide alleles distribute across metadata groups (e.g. tumor vs. normal).

⚠ What humaninFlow does not tell you

  • Whether the peptide is actively transcribed or translated: that requires biological validation (mass spectrometry, RNA-seq, or antibody assays).
  • In silico predictions are designated Evidence Tier E1.
  • The right genetic code for a NUMT in a short contig: pass --table 1 explicitly.
