Humanin and SHLPs, across every mitogenome you have.

humaninFlow runs HumaninFinder over a whole cohort in parallel and gives you one table of peptides, joined to your sample metadata. Use Nextflow or Snakemake; the results are identical.

Get started Source on GitHub

How it works

Give it FASTA files. Get back one table.

Every input runs as its own job, so a thousand mitogenomes take about as long as your cluster allows, not a thousand times longer.

  1. Check

    Each FASTA is validated first: format, sequence symbols and duplicate IDs. Bad input fails in seconds, not hours.

  2. Predict

    HumaninFinder locates the MT-RNR2 gene, reads every frame under the right genetic code and scores Humanin against Pfam PF15040.

  3. Merge

    Predictions from all files are joined to your metadata by sample ID, with a report of the distinct peptide alleles.

Run it

One command, either engine.

Clone the repository, then point it at your files. The container or conda profile brings HumaninFinder along, so there is nothing else to install.

$ nextflow run workflow/nextflow/main.nf -profile docker \
    --input 'cohort/*.fasta' --metadata samples.csv --table 2
$ snakemake -s workflow/snakemake/Snakefile --cores 8 --use-conda \
    --config input_fasta=cohort.fasta metadata=samples.csv table=2

Try it first

Add -profile test (Nextflow) or run Snakemake with no --config to analyse the bundled human and mouse example.

Bring your own setup

Profiles for docker, apptainer, conda and slurm. Snakemake takes --use-conda or --use-apptainer.

Same answer twice

Both engines share the HumaninFinder release and the summary script. CI checks that their outputs match byte for byte.

Results

Everything you need for the next step.

Tables for statistics, sequences for alignment and tracks for a genome browser.

summary/

One set for the whole run.

cohort_humanin_summary.csv · .tsv
Every prediction from every file, with your metadata columns appended.
cohort_unique_peptides.fasta
Each distinct peptide once, ranked by how many samples carry it.
COHORT_ANALYSIS_REPORT.md
Counts per peptide and frame status, and the Humanin alleles found.

raw_predictions/

One set per input file.

<name>_results.csv
Coordinates, strand, frame status, scores (including MT-RNR2 locus density and coverage, which decide the Humanin name) and sequence of each call.
<name>_results.gff3 · .bed · .fasta
Tracks for IGV or JBrowse 2, and the peptide sequences.
<name>_run.json
Options, tool version and the SHA-256 of the input, for your methods section.
