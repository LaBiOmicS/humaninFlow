🧬 Dual-Engine Workflow Pipeline • Nextflow DSL2 & Snakemake

Scalable discovery of Humanin and mitochondrial micropeptides.

humaninFlow is a data-agnostic, publication-grade workflow framework designed to locate, validate and annotate Humanin and SHLP1–6 across circular mitogenomes, large population cohorts, and whole nuclear genome assemblies.

Get Started in 5 Min View on GitHub HumaninFinder Engine

$ nextflow run workflow/nextflow/main.nf \
    --input my_mitogenomes.fasta \
    --metadata cohort_metadata.csv \
    --outdir results/my_cohort \
    --table 2 --circular

Pipeline Architecture

Decoupled stages ensuring data integrity, parallel discovery, and automatic metadata integration.

1. Pre-flight Validation (Linting)
humanin-finder lint • Syntax, IUPAC characters & Circular constraints
↓
2. Core Discovery Engine
MT-RNR2 Profile HMM Synteny • Species Translation (Table 2/1/5) • PF15040 Domain
↓
3. Multi-Omics Cohort Synthesis
Join Metadata (CSV/TSV) • Extract Unique Peptides FASTA • Markdown Report
↓
4. Publication-Ready Outputs
results.csv • results.fasta • results.gff3 • results.bed • run.json
⚡

Dual Orchestration

Identical biological logic executed seamlessly in Nextflow DSL2 (for cloud, HPC/SLURM, container profiles) or Snakemake (for Conda and local workstations).

🔍

Nested sORF Resolution

Solves the classic gene-finding failure inside structural RNA by mapping the homologous locus in MT-RNR2 before translating species-specific reading frames.

📊

Metadata Integration

Directly binds prediction tables with sample clinical, epidemiological, geographical and experimental metadata (Tumor vs Normal, Clades, Breeds).

Getting Started

Choose your workflow manager and execute in seconds.

# 1. Clone the repository
$ git clone https://github.com/LaBiOmicS/humaninFlow.git
$ cd humaninFlow

# 2. Run with Nextflow on any FASTA dataset
$ nextflow run workflow/nextflow/main.nf \
    --input examples/test_mitogenomes.fasta \
    --metadata examples/test_metadata.csv \
    --outdir results/nextflow \
    --table 2 \
    --circular
# 1. Clone the repository
$ git clone https://github.com/LaBiOmicS/humaninFlow.git
$ cd humaninFlow

# 2. Run with Snakemake
$ snakemake \
    --snakefile workflow/snakemake/Snakefile \
    --config input_fasta=../../examples/test_mitogenomes.fasta \
             metadata=../../examples/test_metadata.csv \
             outdir=../../results/snakemake \
    --cores 4
# Run Nextflow with official container images (zero local dependencies)
$ nextflow run workflow/nextflow/main.nf -profile docker --input data.fasta
$ nextflow run workflow/nextflow/main.nf -profile apptainer --input data.fasta

Execution Recipes

Practical commands tailored to specific genomic tasks.

1. Vertebrate Population Cohorts

Circular complete mitogenomes evaluated under vertebrate mitochondrial genetic code (Table 2):

nextflow run workflow/nextflow/main.nf \
  --input mitogenomes.fasta \
  --metadata cohort_metadata.csv \
  --table 2 --circular

2. Whole Nuclear Genome (NUMT) Search

Scan draft contigs or chromosomes for nuclear insertions under standard code (Table 1):

nextflow run workflow/nextflow/main.nf \
  --input nuclear_wgs.fasta.gz \
  --command scan --table 1 --circular false

3. Invertebrates & Non-Vertebrates

Execute with alternative codes, e.g. Table 5 for insects or Table 9 for echinoderms:

nextflow run workflow/nextflow/main.nf \
  --input drosophila_mt.fasta \
  --table 5 --circular

4. Institutional HPC Cluster (SLURM)

Dispatch jobs to institutional compute clusters using Apptainer/Singularity containers:

nextflow run workflow/nextflow/main.nf \
  -profile apptainer \
  --input massive_cohort.fasta \
  -process.executor slurm -process.queue batch

Outputs & Data Dictionary

Transparent, auditable data deliverables ready for downstream statistical and structural modeling.

Deliverable Format Biological & Technical Content
<prefix>_results.csv CSV Sample ID, peptide name (Humanin, SHLP1-6), frame status (Complete, Interrupted, Incomplete), coordinates, synteny bitscore, HMM bitscore.
<prefix>_results.fasta FASTA Translated amino acid sequences with detailed header annotations (coords, evidence tier).
<prefix>_results.gff3 GFF3 Standard 1-based genomic feature track for genome browsers (IGV, JBrowse).
<prefix>_results.bed BED 0-based half-open coordinates with circular wrap blocks resolved.
cohort_humanin_summary.csv CSV/TSV Integrated master ledger merging locus predictions with user-supplied covariates (tumor/control, breed, country).
cohort_unique_peptides.fasta FASTA Non-redundant unique peptide variants found across the cohort, ranked by frequency.
COHORT_ANALYSIS_REPORT.md Markdown Executive report summarizing discovery rates, completeness percentages and variant distribution.
